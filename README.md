# RAG Document Q&A

A Retrieval-Augmented Generation (RAG) web app. Upload documents and ask questions about their content — answers are grounded in what you uploaded, not general knowledge.

## Features

- Upload **PDF, TXT, CSV, XLSX, XLS, DOCX, MD** files
- Embeddings stored in a persistent **Chroma** vector database
- Answers generated by **OpenAI GPT-4o-mini**
- **Free local embeddings** via HuggingFace `all-MiniLM-L6-v2`
- Chat-style Q&A with source chunk attribution

## Tech Stack

| Layer | Tool |
|---|---|
| UI | Streamlit |
| LLM | OpenAI GPT-4o-mini |
| Embeddings | HuggingFace `sentence-transformers/all-MiniLM-L6-v2` (local) |
| Vector DB | Chroma (persisted to `vectorstore/`) |
| Orchestration | LangChain |

## Setup

### 1. Clone and create a virtual environment

```bash
git clone <repo-url>
cd myRAGProject
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

> The HuggingFace embedding model (~90 MB) downloads automatically on first run.

### 3. Configure your API key

```bash
cp .env.example .env
```

Edit `.env` and set your OpenAI key:

```
OPENAI_API_KEY=sk-...
```

### 4. Run

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501`.

## Usage

1. **Upload tab** — drag and drop one or more documents, click **Process Documents**
2. **Ask tab** — type a question; the answer is drawn from the uploaded content
3. Expand **Sources** under any answer to see which chunks were retrieved

## Notes

- `vectorstore/` is excluded from git — it is created locally on first upload
- `.env` is excluded from git — never commit your API key
- Scanned image PDFs cannot be parsed (no embedded text); use a text-based PDF or run OCR first
